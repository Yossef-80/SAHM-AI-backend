# Tools Development Assignment Matrix

This document outlines the high-value AI tools we need to build for the SAHM OS. Developers should claim a tool, follow the `DEVELOPER_TOOL_GUIDE.md`, and submit their PRs.

---

## 🟢 FREE TOOLS (No Paid APIs Required)

### 1. Facebook/Instagram Organic Poster
* **Description:** A tool that takes a finished creative and caption from the AI and publishes it directly to a brand's Facebook or Instagram page.
* **Agent:** `layla` (Creative Agent)
* **API Required:** Meta Graph API (Free).
* **Database Tables:** `Campaign` (to associate the post), `Creative` (to mark it as published).
* **Tool Type:** Action (Database Writer + API Caller)
* **Assigned To:** ____________________

### 2. Google Analytics (GA4) Performance Fetcher
* **Description:** Connects to a brand's Google Analytics account to fetch website traffic, bounce rates, and conversion metrics over a specific date range.
* **Agent:** `karim` (Analyst Agent)
* **API Required:** Google Analytics Data API (Free).
* **Database Tables:** None (Read-Only). The agent reads the data and generates an `Insight`.
* **Tool Type:** Read-Only
* **Assigned To:** ____________________

### 3. SEO Keyword Clustering
* **Description:** A tool that takes a list of raw SEO keywords (from our existing web searches) and groups them into thematic clusters based on search intent.
* **Agent:** `omar` (Strategist Agent)
* **API Required:** None (Use local Python libraries like `scikit-learn` or `nltk`, or just prompt an LLM).
* **Database Tables:** `Recommendation` (Suggests content silos based on clusters).
* **Tool Type:** Action
* **Assigned To:** ____________________

## 🔴 PAID TOOLS (Require API Budgets/Keys)

### 4. Competitor Ad Library Scraper
* **Description:** Scrapes the Facebook Ad Library to find exactly what ads a specific competitor is currently running. Extremely valuable for Nour.
* **Agent:** `nour` (Researcher Agent)
* **API Required:** Apify (Facebook Ads Scraper Actor - Paid).
* **Database Tables:** `BrandMemoryItem` (Save competitor ad copy as long-term memory reference).
* **Tool Type:** Action + Read
* **Assigned To:** ____________________

### 5. DALL-E / Midjourney Image Generator
* **Description:** Takes an image prompt generated by Layla and generates a real, high-quality ad image, saving it to our local storage or cloud bucket.
* **Agent:** `layla` (Creative Agent)
* **API Required:** OpenAI (DALL-E 3) or Midjourney API wrapper (Paid).
* **Database Tables:** `Creative` (Save the generated image URL and the prompt used).
* **Tool Type:** Action
* **Assigned To:** ____________________

### 6. SEO Backlink & Authority Checker
* **Description:** Fetches the Domain Authority and top backlinks for a specific competitor's website.
* **Agent:** `nour` (Researcher Agent)
* **API Required:** DataForSEO or Ahrefs API (Paid).
* **Database Tables:** `Insight` (Save the authority gap between our brand and the competitor).
* **Tool Type:** Action + Read
* **Assigned To:** ____________________
